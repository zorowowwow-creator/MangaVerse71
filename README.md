# MangaVerse71

Manga Verse — Архитектура проекта

1. Общая информация о проекте

Manga Verse — настольное приложение для поиска, просмотра и организации манги и комиксов в единой цифровой библиотеке.

Основная цель проекта — создать удобную платформу, в которой пользователь сможет находить произведения через внешние источники, просматривать информацию о них и сохранять понравившиеся произведения в личную библиотеку.

2. Используемые технологии

* C# — основной язык программирования.
* .NET 10 — платформа разработки приложения.
* Avalonia UI — технология создания графического интерфейса.
* MVVM — архитектурный шаблон приложения.
* CommunityToolkit.Mvvm — инструмент для реализации команд и привязки данных.
* Entity Framework Core — технология взаимодействия с базой данных.
* SQLite — локальная база данных.
* AniList API — внешний источник информации о манге.

3. Архитектура приложения

Проект построен на основе архитектурного шаблона MVVM, который разделяет приложение на три основные части.

3.1. Models (Модели)

Отвечают за структуру и хранение данных приложения.

Основные модели:

* Manga — информация о манге.
* Comic — информация о комиксах.
* Chapter — информация о главах.
* LibraryItem — элемент личной библиотеки.

3.2. Views (Представления)

Отвечают за отображение графического интерфейса и взаимодействие с пользователем.

Основные страницы:

* MainWindow — главное окно приложения.
* HomePage — главная страница.
* MangaSearchPage — поиск манги.
* ComicsSearchPage — поиск комиксов.
* MyLibraryPage — личная библиотека.
* MangaDetailsPage — подробная информация о произведении.

3.3. ViewModels (Модели представления)

Отвечают за логику работы интерфейса и обработку действий пользователя.

Основные компоненты:

* MainViewModel — управление главным окном.
* Навигация между страницами.
* Команды поиска.
* Управление библиотекой.
* Привязка данных между моделями и представлениями.

4. База данных

Для локального хранения информации используется SQLite совместно с Entity Framework Core.

База данных предназначена для:

* Сохранения информации о произведениях.
* Хранения элементов личной библиотеки.
* Получения сохранённых записей.
* Управления локальными данными приложения.

Entity Framework Core обеспечивает взаимодействие между программой и базой данных через контекст данных DbContext.

5. Взаимодействие с внешними API

AniList API

Используется для:

* Поиска манги по названию.
* Получения информации о произведениях.
* Получения результатов поиска.

Внешние источники комиксов

Предусматривается возможность подключения дополнительных API для поиска комиксов и получения информации о публикациях.

6. Принцип работы приложения

1. Пользователь запускает Manga Verse.
2. Открывается главное окно приложения.
3. Пользователь выбирает нужный раздел.
4. При поиске манги приложение отправляет запрос к AniList API.
5. Полученные результаты отображаются в интерфейсе.
6. Пользователь может выбрать произведение.
7. Доступные произведения можно добавлять в личную библиотеку.
8. Локальные данные сохраняются в базе SQLite.
9. Сохранённые произведения можно повторно просматривать в личной библиотеке.

7. Схема взаимодействия компонентов

flowchart TD
    A[Пользователь] --> B[Интерфейс Avalonia UI]
    B --> C[ViewModels]
    C --> D[Models]
    C --> E[Внешние API]
    E --> F[AniList API]
    E --> G[Другие источники]
    C --> H[Entity Framework Core]
    H --> I[SQLite]
    I --> J[Личная библиотека]
    J --> B

8. Основные задачи проекта

* Создание единой цифровой библиотеки манги и комиксов.
* Реализация поиска произведений.
* Получение информации из внешних источников.
* Локальное хранение пользовательской библиотеки.
* Разделение логики и интерфейса по шаблону MVVM.
* Создание удобного и понятного графического интерфейса.
